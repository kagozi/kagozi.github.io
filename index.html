mqtt_rl_bridge · Python package
Code
Tiny library that lets reinforcement learning agents interact with real hardware over MQTT with minimal boilerplate. Works with Stable-Baselines3, RLlib, CleanRL, or custom training loops. Designed for robotics, smart HVAC, and embedded RL experiments.
Python MQTT RL Stable-Baselines3 IoT
RL-Controlled Indoor Air Quality Fan · RL-IoT system
Event-driven PPO agent controlling a DC fan based on AQI, TVOC, and eCO2 readings. Uses Raspberry Pi, ENS160 sensors, and mqtt_rl_bridge to close the loop between environment, policy, and hardware, optimizing air quality and energy consumption.
PPO Raspberry Pi ENS160 Edge AI
Simulation + real-world prototype
RL-Augmented Brain Tumor Segmentation · BraTS 2020
Explores Proximal Policy Optimization as a meta-controller over segmentation policies for brain tumor MRI. Investigates sample-efficient reward designs, curriculum learning, and integration with standard U-Net pipelines.
Medical imaging PPO PyTorch BraTS 2020
Research in preparation
GastroVision GI Pathology Classifier · Deep ensemble
Deep learning framework for multi-class gastrointestinal endoscopy image classification using CNNs and transformers (ResNet, DenseNet, EfficientNet, ViT, Swin). Combines adaptive focal loss with class weighting and AUC-weighted ensembles.
CNN ViT Class imbalance Ensembles
Under review / in preparation
Hybrid BEIR Search Engine · IR system
PostgreSQL-backed hybrid dense–sparse retrieval stack for BEIR datasets (SciFact, TREC-COVID, etc.). Integrates BM25, bi-encoders, and cross-encoders with learned fusion weights and nDCG@10-driven evaluation pipelines.
Information Retrieval PostgreSQL HNSW BEIR
IEEE-style manuscript in progress
Bidirectional ASL Gloss ↔ English Translation · Specialized T5
Designs a specialized neural architecture over T5 for American Sign Language gloss ↔ English translation, integrating gloss-aware embeddings, syntactic constraints, and bidirectional training routines for low-resource, structured language pairs.
NLP Transformers T5 Sign language
Thesis work
PTB-XL ECG Classification · Time-freq + Transformers
Combines 2D scalogram/phasogram representations of ECG signals with CNNs and transformer-based models. Evaluates BCE vs focal variants and ensembles across domains to improve arrhythmia detection.
