mqtt_rl_bridge · Python package
Package
Tiny library that lets reinforcement learning agents interact with real hardware over MQTT with minimal boilerplate. Works with Stable-Baselines3, RLlib, CleanRL, or custom training loops. Designed for robotics, smart HVAC, and embedded RL experiments.

Hybrid BEIR Search Engine · IR system
Repo
PostgreSQL-backed hybrid dense–sparse retrieval stack for BEIR datasets (SciFact, TREC-COVID, etc.). Integrates BM25, bi-encoders, and cross-encoders with learned fusion weights and nDCG@10-driven evaluation pipelines.

PTB-XL ECG Classification
Repo
Combines 2D scalogram/phasogram representations of ECG signals with CNNs and transformer-based models. Evaluates BCE vs focal variants and ensembles across domains to improve arrhythmia detection.
